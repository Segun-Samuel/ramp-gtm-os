# Ramp: Customers (raw research)

Researched: 2026-11-14

Scope: Public-source facts on who uses Ramp (ramp.com, corporate card / spend management / finance automation): customer counts and scale claims, named customers, case studies, testimonials, industries and segments Ramp highlights, review-site scores, and switcher stories. Raw facts only. No conclusions or recommendations.

Method notes (read first):
- Pages were read with a page-to-text fetch tool that returns a summary, not raw HTML. Quotes are copied as the tool returned them. Many were returned as excerpts (the tool shortened long quotes), so a trailing fragment, a missing second sentence or a curly-versus-straight apostrophe can differ from the live page. Spot-check a quote against the live page before using it in copy.
- All metrics in case studies are "claimed by Ramp" (vendor-published pages), even where a customer is quoted.
- "Mid-size", "SMB" and "Enterprise" labels are the labels Ramp prints on each case study page, not employee counts, unless an employee count is given.
- G2, Capterra, Gartner Peer Insights, Software Advice, GetApp and TrustRadius returned HTTP 403 to direct fetches in the first pass. Second pass: TrustRadius and Gartner Peer Insights were readable with crawl4ai (sections 6.3 and 6.6 now hold live data). G2, Capterra, Software Advice and GetApp data below remains first-pass, from search-result excerpts or mirrors and labelled as such.
- Date for every "checked" is 2026-11-14.
- Second pass (2026-11-14): pages were re-read with crawl4ai, which returns full page Markdown (not a summary). Case-study quotes below were re-checked against the crawled text. Where a first-pass quote was an excerpt, the full wording is given in a "Second pass" bullet under that case study. Crawled text uses curly apostrophes and, in places, em dashes; quotes in this file keep straight apostrophes and straight double quotes, and keep a dash only where the page has one. Raw crawls are not stored in the repo. See the "Second pass (2026-11-14)" section at the end of the file for what was added, corrected and left blocked.
- Review sites in the second pass: TrustRadius and Gartner Peer Insights were read through crawl4ai (sections 6.3 and 6.6 rewritten). G2, Capterra and Trustpilot were not re-read in the second pass (handled separately); their entries below are first-pass.
