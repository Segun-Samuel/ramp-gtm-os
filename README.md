# ramp-gtm-os

A GTM Context OS for Ramp (https://ramp.com), built with Claude Code for the Treford GTM Engineering Bootcamp.

It holds Ramp's go-to-market context as plain text files: sourced research, ICP and personas, buying signals, the GTM system design and one target workflow spec. Claude Code reads `CLAUDE.md` at the start of every session and uses the folders it points to.

This is a learning project built from public information. It is not affiliated with Ramp.

See `CLAUDE.md` for what each folder is for.
